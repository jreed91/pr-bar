The desktop app gets its own layout: titles and list rows are left whole for the app to truncate rather than cut to a column count, Details is the full bar's primary button, and an open row's card is indented instead of boxed. A description image too large to show on the desktop is shrunk to a JPEG with macOS's `sips` first, and stays a link where `sips` is not available. The bar and pane tests now run on the terminal and the desktop.
